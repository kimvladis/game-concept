# game-concept

в играбельный кусок.

На входе идея в пару предложений. На выходе кадр 16:9 из «вышедшей» 2D-игры, с интерфейсом, и бриф к нему.

## Установка одним промптом

Отправьте этот промпт вашему агенту (Claude Code или Codex):

```text
Установи скилл game-concept https://github.com/kimvladis/game-concept
```

В репозитории две редакции одного скилла. Claude Code берёт папку `claude/`, Codex — папку `codex/`. Дальше отправьте
`/game-concept` в Claude Code или `$game-concept` в Codex и идею или просто скажите «сделай концепт игры, где…».

---

**game-concept** рисует идею 2D-игры как кадр из уже вышедшей игры: 16:9, игровая камера, интерфейс, герой посреди
главного действия. ref2game повторяет референс почти один в один (камеру, раскладку, палитру, масштаб, интерфейс),
поэтому каждая деталь кадра — заказ на будущую игру. Красивая иллюстрация без игры — плохой концепт.

**Концепт — это ТЗ, на которое можно посмотреть.**

## Две редакции

| | `claude/` для Claude Code | `codex/` для Codex |
|---|---|---|
| Генерация картинок | встроенный image_gen из Codex через CLI `codex`, подписка Antigravity (`agy`) или платный Gemini API; если нет ничего, вы получаете промпт | по умолчанию встроенный imagegen сессии; `agy` и Gemini API, если они настроены |
| Вопросы | варианты ответа, рекомендованный первым | через инструмент ввода Codex или коротко в чате |
| Два варианта | два фоновых запуска, выбираете, когда придут | генерируются параллельно и показываются до конца хода |
| Сверка надписей | агент читает вырезки ×6–8 | сабагент читает вырезки вслепую, без промпта, если делегирование доступно |

Шаблон промпта, проверки, `patch.py` и эталоны в обеих редакциях одинаковые.

## Как это выглядит

```text
Вы       /game-concept  фермер ночью защищает урожай фонариком
Агент    Один раунд вопросов: камера, стиль, какой момент показать.
Агент    Два варианта в фоне, они отличаются по одному открытому вопросу; рядом, с отчётом, какие слоты вышли.
Вы       Второй, только в интерфейс нужен счётчик дней.
Агент    Одна правка — одно изменение. Каждая надпись прочитана по буквам на вырезке ×6:
         «ROCKS» вышло как «ROCRS», область возвращена из прошлой версии.
Агент    concept/final.png и BRIEF.md готовы. Дальше: /ref2game с final.png.
```

## Пайплайн

| # | Фаза | Вы | Агент |
|---|---|---|---|
| 1 | Спросить | отвечаете на один раунд вопросов | спрашивает только камеру, стиль и момент; остальное решает сам и называет решения |
| 2 | Промпт | — | заполняет каждый слот шаблона: камера, стиль, мир, момент, угроза, свет, интерфейс, кадр |
| 3 | Генерация | выбираете один из двух | два варианта, отличных по одному открытому вопросу, и отчёт по слотам для каждого |
| 4 | Правки | говорите, что поменять | одна правка — одно изменение; надписи сверяются по буквам; испорченный текст возвращается через `patch.py` |
| 5 | Сдача | забираете `concept/` | `final.png`, `final.prompt.txt` и `BRIEF.md`, который отвечает на первые вопросы ref2game |

## Генераторы картинок

| Генератор | Что нужно | Скорость и цена | Размер |
|---|---|---|---|
| Встроенный imagegen из Codex (в Claude Code — `scripts/codex_gen.py`) | Codex; в Claude Code — `codex` в PATH, вход выполнен | 2–3 мин на картинку; расходует лимиты Codex, ключ API не нужен | какой выберет инструмент, для 16:9 ~1672×941; по умолчанию в Codex-редакции |
| Подписка Antigravity (`scripts/agy_gen.py`) | `agy` в PATH, вход выполнен | 40–90 с на картинку; квота вашего тарифа Google, ключ API не нужен | ~1376×768 |
| Платный Gemini API (`scripts/gemini_image.py`) | `GEMINI_API_KEY` | 15–40 с на картинку; ~$0,07 за 2K, весь концепт ~$0,3–0,5 | 2752×1536, Nano Banana 2.1 |
| Вручную | ничего | ваше время | агент пишет промпт, вы вставляете его в приложение Gemini и кладёте картинку в `concept/` |

У всех трёх скриптов одни флаги, платный печатает цену каждой картинки. Если работает больше одного генератора, агент
добавит выбор в раунд вопросов; в Codex первым идёт imagegen. ref2game рисует теми же генераторами, так что выбранный
переходит туда же.

## Чем он отличается

- 🎮 **Кадр из вышедшей игры, а не постер.** Камера на игроке, персонажи ~1/10 высоты кадра, интерфейс в панелях
  по краям. Ни логотипа, ни перспективы, ни размытия глубины.
- 🧩 **Каждый слот заполнен.** Камера, стиль, мир, момент, угроза, свет, интерфейс и кадр, на английском, по шаблону.
  Пустой слот — дыра в будущей игре.
- 🔤 **Текст — это правила.** Короткие подписи и числа в интерфейсе («Energy», «84/100», «LV 7», «03:12») делают из
  картинки игру. Nano Banana рисует их чисто, поэтому скилл их пишет.
- 🔍 **Буквы проверяются, а не принимаются на веру.** Правка перерисовывает весь кадр и может испортить текст там, где
  её не просили. Каждая надпись читается на вырезке ×6–8. Испорченная возвращается из версии, где она верна:
  `patch.py` откажет, если раскладка вокруг области сдвинулась.
- 🛠️ **Собираемо для ref2game.** Одна проекция, 3–5 типов актёров (каждому нужен риг), предметы стоят отдельно,
  а эффекты только те, что пишутся кодом: свет, частицы, вспышки, взрывы, дождь.
- ⚖️ **Варианты отвечают на вопрос.** Два варианта различаются одним открытым выбором (стиль, момент или камера),
  а не случайными дублями одного промпта.

## Каким должен быть концепт

Скилл равняется на два кадра — референсы из [примеров ref2game](https://github.com/kimvladis/ref2game/blob/main/README.ru.md#примеры).
ref2game сделал из каждого играбельный кусок.

### Мадам Зора: от идеи до живой игры

Уютный симулятор гадания на таро: игрок пишет вопрос, тянет карты, а гадалка толкует расклад. Два варианта нарисованы
встроенным image_gen из Codex. Открытый вопрос — есть ли в кадре сама гадалка.

### Hands > Mouths: оборона колонии в пустыне после коллапса

Игрок управляет племенем, распределяя людей по работам, и никогда не выделяет юнитов. Два раунда по два варианта, все
четыре нарисованы на подписке Antigravity (`agy_gen.py`).

В обоих раундах открытый вопрос — момент: кто в центре кадра. Правила игры несёт интерфейс: люди, вода, металлолом,
дух, день, таймер бури и работы в слотах действий с числом людей на каждой.

**Раунд 1.** Промпт просит HD-пиксель с тёмной обводкой и cel-тенями, а генератор рисует гладкую cel-иллюстрацию.

## Что нужно

Claude Code или Codex, Python 3.9+ с Pillow и NumPy, macOS или Linux. Codex рисует встроенным imagegen. В Claude Code
нужно одно из трёх: Codex CLI (`codex`) с выполненным входом, Antigravity CLI (`agy`) с входом в аккаунт Google или
`GEMINI_API_KEY`. Если генератора нет совсем, агент отдаст вам промпт.

## В паре с ref2game

[ref2game](https://github.com/kimvladis/ref2game) превращает одну картинку в живую играбельную 2D-игру. game-concept
рисует эту картинку, когда есть только идея: `concept/BRIEF.md` отвечает на первый раунд вопросов ref2game,
а `concept/final.png` становится референсом.
